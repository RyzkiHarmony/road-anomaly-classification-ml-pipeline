# Role
Act as a Senior Machine Learning Engineer and Data Scientist specializing in sensor data analysis (accelerometer & GPS) for road condition monitoring.

# Context
I am developing a Road Damage Detection System based on crowdsourced data. 
- **Data Source**: Android application collecting Accelerometer (X, Y, Z) and GPS data.
- **Sampling Rate**: 50-100 Hz.
- **Goal**: Detect road anomalies (potholes, bumps) and classify them using a Random Forest model.
- **Current Status**: The Android app is ready and produces CSV files with raw sensor data.

# Objective
Create a complete Python-based Machine Learning pipeline to process the raw sensor data, train a Random Forest model, and detect road damage events.

# Input Data Specification
The input is a CSV file generated by the Android app with the following columns:
- `timestamp` (Long, milliseconds)
- `accelX`, `accelY`, `accelZ` (Float, m/s²)
- `latitude`, `longitude` (Double)
- `speed` (Float, m/s)
- `accuracy` (Float)

# Requirements & Tasks

Please generate Python code (using `pandas`, `numpy`, `scikit-learn`, `scipy`) to implement the following pipeline modules, strictly following the architecture defined below:

## 1. Preprocessing Module (`preprocessing.py`)
- **Noise Filtering**: Apply a Low-Pass Filter (e.g., Butterworth) to remove high-frequency noise from accelerometer data.
- **Reorientation**: Align the accelerometer data to a global coordinate system (remove the effect of device orientation/gravity). Calculate the vertical acceleration component ($a_v$).
- **Windowing**: Implement a Sliding Window approach (e.g., 2-second windows with 50% overlap) to segment the continuous stream.

## 2. Feature Extraction Module (`features.py`)
For each time window, extract time-domain features relevant for vibration analysis:
- **Statistical**: Mean, Standard Deviation, Variance, RMS (Root Mean Square).
- **Extremes**: Min, Max, Peak-to-Peak Amplitude.
- **Dynamics**: Jerk (rate of change of acceleration).
- **Energy**: Signal energy or spectral energy (optional).

## 3. Model Development (`detection.py`)
- **Algorithm**: Random Forest Classifier.
- **Training**: 
    - Function to load labeled training data (assume a dataset exists with labels: 'Normal', 'Pothole', 'Bump').
    - Split data into Train/Test sets.
    - Train the Random Forest model.
- **Prediction**:
    - Function to take a processed window (features) and output a class + probability/confidence.
- **Persistence**: Save the trained model using `joblib` or `pickle`.

## 4. Post-Processing & Mapping (`aggregation.py`)
- **Event Localization**: For detected damage events, map the window's timestamp back to the GPS coordinates (Latitude, Longitude).
- **Severity Score**: Define a heuristic for severity based on the prediction probability and the magnitude of the vertical acceleration peak.

# Output Deliverables
Provide the complete Python code for the modules above. Ensure the code is modular, well-documented, and ready to be integrated into a Django backend or run as a standalone script for testing.

# Notes
- Handle edge cases like missing GPS data or variable sampling rates (resample if necessary).
- Focus on high precision to avoid false positives (users complaining about false alarms).
